The compactness property can seem a bit paradoxical. Consider, for
example, the following apparently valid argument with infinitely many
premises.
There is more than one angel.
There are more than two angels.
..
.
There are infinitely many angels.
If this argument is valid, then compactness entails that the conclusion is
a logical consequence of only finitely many of the premises. In particular,
there is a largest natural number n such that the premise “there are more
than n angels” implies the conclusion “there are infinitely many angels,”
which seems obviously wrong. The solution to this little puzzle is simply that propositional logic renders a false verdict about the structure of
this argument. But that shouldn’t be surprising; we already know that
propositional logic provides only a partial picture of what makes arguments
valid.
